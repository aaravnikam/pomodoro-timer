# Pomodoro Timer

A simple Pomodoro Timer built with HTML, CSS, and JavaScript. This timer is designed to help you stay focused while studying by utilizing the Pomodoro Technique. Enjoy a clean, non-distracting UI with subtle animations for an enhanced user experience.

## Features

- **Work/Break Sessions:** Automatically switches between work and break sessions.
- **Clean UI:** Minimalistic and distraction-free design.
- **Responsive Design:** Works well on desktops and mobile devices.
- **Easy Controls:** Use the Start, Pause, and Reset buttons to control the timer.
- **Smooth Animations:** Enjoy subtle animations that enhance the overall user experience.
